📋 1. 프로젝트 기본 정보 및 작동 버튼 (Scripts)
이 구역은 프로젝트의 이름표와, 터미널에서 실행할 '단축키(명령어)'들을 정의합니다.

"name": "fe": 아까 맨 처음 정했던 우리 패키지의 이름입니다.

"type": "module": 최신 자바스크립트 모듈 시스템(import/export)을 사용하겠다는 선언입니다.

"scripts": 개발팀이 터미널에서 npm run [명령어] 형태로 누를 수 있는 버튼들입니다.

dev: 로컬 테스트 서버를 켭니다. (가장 많이 쓰는 버튼)

build: 실제 유저에게 배포하기 위해 코드를 압축하고 포장(빌드)합니다.

lint: 코드에 문법 에러나 오타가 없는지 프로젝트 전체를 싹 검사합니다.

preview: build로 포장된 결과물이 배포 서버에서 잘 돌아갈지 미리 띄워보는 기능입니다.

📦 2. dependencies (서비스 배포 시 포함되는 '핵심 부품')
이곳에 적힌 패키지들은 실제 유저들이 우리 웹사이트에 접속했을 때 브라우저로 다운로드되어 작동하는 진짜 서비스 부품들입니다.

기본 뼈대

react & react-dom: 우리 프론트엔드 화면을 그리는 가장 기본이 되는 핵심 UI 엔진입니다.

오디오 및 데이터 제어 (서비스의 심장)

tone: Tone.js입니다. 브라우저에서 소리를 재생하고, 주파수 충돌을 감지하거나 파형을 시각화하는 등 웹 오디오 제어를 위한 최상위 핵심 엔진입니다.

zustand: 오디오 재생 시간, 선택된 트랙, 볼륨 등 여러 컴포넌트가 공유해야 하는 '클라이언트 상태'를 아주 가볍고 빠르게 관리해 주는 저장소입니다.

@tanstack/react-query: 서버(백엔드)에서 트랙 목록, 프로젝트 정보 등의 데이터를 가져오고, 저장하고, 캐싱(기억)하는 것을 관리해 주는 통신 전용 상태 관리자입니다.

UI/UX 및 디자인 시스템 (shadcn 생태계)

radix-ui: 눈에 보이는 디자인은 없지만, 웹 접근성(키보드 조작 등)이 완벽하게 구현된 뼈대 컴포넌트입니다. (shadcn의 핵심 기반)

class-variance-authority (cva): 버튼의 크기(sm, md, lg)나 색상(기본, 경고) 등 '디자인 종류(Variant)'를 깔끔하게 관리해 주는 도구입니다.

clsx & tailwind-merge: 복잡하게 꼬인 Tailwind 디자인 클래스 이름들을 충돌 없이 예쁘게 하나로 합쳐주는 도구들입니다.

lucide-react: 프로젝트 전체에서 사용할 깔끔하고 가벼운 아이콘 세트입니다.

@fontsource-variable/geist: Vercel에서 만든 아주 깔끔한 최신 개발용 폰트(Geist)입니다.

tw-animate-css: Tailwind용 애니메이션 플러그인입니다. (참고: 아래 dev에 있는 tailwindcss-animate와 역할이 겹칩니다. 보통 tailwindcss-animate 하나만 씁니다.)

shadcn: UI 컴포넌트를 터미널에서 다운받을 수 있게 해주는 도구입니다.

🛠️ 3. devDependencies (개발할 때만 쓰는 '공장 도구')
이곳에 적힌 패키지들은 개발자들이 코드를 짜고 테스트할 때만 쓰이고, 실제 유저에게는 배포되지 않는 도구들입니다. (그래서 용량이 커도 서비스 속도에 지장을 주지 않습니다.)

포장 기계 (번들러)

vite: 코드를 눈부시게 빠른 속도로 화면에 띄워주고, 나중에 배포용으로 압축해 주는 최신 공장 기계입니다.

@vitejs/plugin-react: Vite 기계가 React 코드를 알아듣게 해주는 전용 번역기입니다.

타입 및 문법 검사 (TypeScript 생태계)

typescript: 코드에 빨간 줄을 그어 개발자의 실수를 막아주는 깐깐한 문법 검사기입니다.

@types/node, @types/react, @types/react-dom: 타입스크립트가 Node.js와 React의 내부 단어들을 에러 없이 알아듣도록 제공하는 '단어 사전'들입니다.

디자인 번역 및 호환성 (CSS 생태계)

tailwindcss: 우리가 쓸 핵심 CSS 디자인 프레임워크입니다.

postcss & autoprefixer: 작성된 CSS를 호환성에 맞게 다듬고 브라우저 공통 표준으로 번역해 주는 숨은 일꾼들입니다.

tailwindcss-animate: shadcn의 아코디언, 모달 등의 부드러운 애니메이션을 담당하는 플러그인입니다.

코드 품질 관리관 (ESLint 생태계)

eslint, @eslint/js, typescript-eslint, eslint-plugin-* 등: "변수 이름은 이렇게 지어라", "이 코드는 성능에 안 좋으니 수정해라" 등 팀원 전체의 코드 스타일을 일관되게 맞추고 품질을 검사해 주는 깐깐한 잔소리꾼(Linter) 세트입니다.
